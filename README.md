## Prerequisites
- JDK 17+
- Apache Maven 3.9+

## Getting started
```bash
git clone https://github.com/swankygawk/CsvWriter.git
cd CsvWriter
```

## Launching demo
```bash
mvn compile exec:java -Dexec.mainClass="org.writer.Application"
```
Generated CSV files will be located in the `output` directory

## Launching tests
```bash
mvn test
```
